# دیده‌بان قیمت (Dideban Price)

دیده‌بان قیمت برنامه‌ای برای دنبال‌کردن زندهٔ قیمت‌ها و تحلیل بازار است.

## امکانات

- قیمت زندهٔ طلا، ارز خارجی، سکه، نقره، نفت، بورس، رمزارز و فلزات
- نمودارهای قیمت
- تحلیل حباب سکه و طلا با ارزش‌گذاری ۷ روزه
- ماشین‌حساب سود
- تبدیل ارز
- مقایسهٔ اقلام
- جستجو
- هشدار قیمت و گزارش شبانه که با اعلان پوش (Push Notification) ارسال می‌شود
- تم روشن و تیره
- رابط کاربری فارسی و راست‌به‌چپ
